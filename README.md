# MARFANS — Ensemble face au syndrome de Marfan

Site web informatif dédié au syndrome de Marfan, destiné à informer, accompagner et sensibiliser les personnes concernées, leurs proches et le grand public.

## 🎯 Objectifs du projet

- Présenter le syndrome de Marfan, ses causes et ses symptômes.
- Informer sur le diagnostic, les traitements et le suivi médical.
- Accompagner les personnes concernées dans leur quotidien.
- Présenter les droits des patients et les ressources disponibles.
- Permettre aux visiteurs de témoigner et de soutenir l'association.

## 🎨 Identité visuelle

Le site adopte une interface épurée, accessible et moderne, avec une identité visuelle cohérente sur l'ensemble des pages.

| Élément | Valeur |
|---|---|
| Police principale | `Raleway`, `Roboto`, sans-serif |
| Couleur principale | `#A8323E` |
| Couleur du texte | `#333333` |
| Couleur de fond | `#FFFFFF` |
| Style général | Épuré, moderne et accessible |

### Variables CSS


```css
:root {
    font-family: "Raleway", Roboto, sans-serif;

    --couleur-principale: #A8323E;
    --couleur-texte: #333333;
    --couleur-fond: #FFFFFF;
}
```

La couleur principale est utilisée notamment pour les titres, les éléments de navigation et les éléments graphiques importants.

## 🧭 Navigation

Le site s'organise autour des rubriques suivantes :

- **Accueil** : présentation générale de l'association.
- **S'informer** : informations sur le syndrome de Marfan.
- **Se soigner** : diagnostic, traitements et suivi médical.
- **Son quotidien** : conseils et accompagnement au quotidien.
- **Ses droits** : informations sur les droits des personnes concernées.
- **Témoigner** : partage d'expériences et de témoignages.
- **Je donne** : soutien aux actions de l'association.

## 🚀 Lancer le projet

1. Cloner le dépôt GitHub ou télécharger les fichiers du projet.
2. Ouvrir le dossier du projet dans un éditeur de code, comme Visual Studio Code.
3. Ouvrir `index.html` dans un navigateur.
4. Pour faciliter le développement, utiliser l'extension **Live Server** de Visual Studio Code.

## ♿ Accessibilité et bonnes pratiques

- Utiliser une structure HTML sémantique (`header`, `nav`, `main`, `section`, `footer`).
- Garantir une bonne lisibilité des textes et un contraste suffisant.
- Adapter la mise en page aux ordinateurs, tablettes et smartphones.
- Ajouter des textes alternatifs descriptifs aux images.
- Utiliser des titres hiérarchisés et des liens explicites.
- Vérifier l'exactitude des informations médicales à l'aide de sources fiables.
